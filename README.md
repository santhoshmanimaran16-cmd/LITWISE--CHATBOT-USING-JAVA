# LitWise (plain Java + HTML)

1. Open this folder in VS Code (File > Open Folder).
2. Install "Extension Pack for Java" if you haven't.
3. Open LitWise.java and click Run above main().
4. Visit http://localhost:8080

Or from a terminal in this folder:  java LitWise.java
Needs JDK 17+. Internet is needed for fonts and the PDF reader (pdf.js).
